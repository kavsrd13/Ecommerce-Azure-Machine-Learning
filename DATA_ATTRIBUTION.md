# Olist dataset attribution

This noncommercial teaching repository contains an unmodified archive of the
**Brazilian E-Commerce Public Dataset by Olist**, made available by Olist and
Francisco Magioli at
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce.

The nine original CSV files in `datasets/olist/Ecommerce Dataset.zip` retain the
source dataset's **Creative Commons Attribution-NonCommercial-ShareAlike 4.0
International (CC BY-NC-SA 4.0)** license:
https://creativecommons.org/licenses/by-nc-sa/4.0/.

You may copy and adapt the dataset for noncommercial use with appropriate credit,
a link to the license, an indication of changes, and the same license for
adaptations. The archive itself is unmodified; features and labels generated by
these exercises are adaptations for teaching. Neither Olist nor Kaggle endorses
this course. Do not use this bundled dataset for a paid/commercial offering
without resolving the license terms first.

The dataset is historical (2016-2018) and anonymized, but real commercial data.
Review applicable institutional data-handling policies before distributing
student-generated exports. Source code and teaching notes are not automatically
relicensed by the dataset license; the dataset notice applies to the data.
